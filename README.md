# Splice サンプル整理ツール

Spliceでダウンロードしたサンプルを整理するための
PowerShellコードです。

YouTube動画で紹介している方法の配布用ページです。

## ファイルについて

### Splice サンプル振り分け コード.txt

SpliceのSamplesフォルダー内を検索し、
ファイル名・フォルダー名をもとに以下のフォルダーへ自動分類します。

- KICK
- SNARE
- CLAP
- RIM
- HIHAT
- CRASH
- TAMBOURINE
- PERC
- 808
- BASS
- LOOP
- VOCAL
- ATMOSPHERE
- FX
- OTHER

元ファイルは削除・移動せず、
指定した保存先へコピーする仕様です。

### Splice サンプルフォルダ作成 コード.txt

01_KICK ～ 15_OTHER のフォルダーを
まとめて作成するためのコードです。

※自動振り分けコードを使用する場合は、
こちらのフォルダー作成コードを先に実行する必要はありません。

## 対応環境

- Windows 10 / 11
- PowerShell 5.1以降を想定
- Mac / Linuxは対象外

## 使用上の注意

ファイル名・フォルダー名をもとに自動判定するため、
すべてのサンプルを正確に分類できることを保証するものではありません。

元ファイルを削除・移動しない仕様ですが、
念のため重要なデータは事前にバックアップしてください。

PC環境、アクセス権限、ファイル構成などによって
正常に動作しない場合があります。

コードの使用および実行結果をご自身で確認のうえ、
自己責任でご使用ください。
